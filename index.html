Wiring in your audio

The study runs in demo mode right now, synthesising placeholder melodies so you can walk the whole flow. To run it for real:

  1. Render each clip as seed → 2s silence → continuation, one file per system per seed.
  2. Give every file an opaque name — c/9f3a1b.mp3, not Aprime/el_mar.mp3. Filenames show up in the network tab.
  3. Paste your sessions into CONFIG.sessions and set CONFIG.demo = false.
  4. Each clip needs boundary (seconds at which the continuation begins) and duration, so the handoff bar can draw itself. Add instrument per trial and it's shown on screen and recorded in the results.
  5. Assign the instrument by seed, so both clips in a pair share one timbre. A timbre difference inside a pair would get judged instead of the melody.
  6. Apply a ~15 ms fade where the seed ends and where the continuation starts, or a note cut mid-attack will click.
